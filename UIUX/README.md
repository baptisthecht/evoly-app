# Maquettes de la refonte A3

Pages HTML autonomes (données fictives), à ouvrir dans un navigateur. Elles ont servi à choisir la direction du
tableau de bord ; les décisions sont dans [`docs/DECISIONS.md`](../docs/DECISIONS.md) et les consignes à suivre dans
[`docs/INTERFACE.md`](../docs/INTERFACE.md).

| Fichier                | Contenu                                                                                                          |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `propositions.html`    | Le constat (tics relevés dans le code) et les trois pistes de départ : A l'outil, B la charte assainie, C Jour J |
| `propositions-a.html`  | La piste A avec plus ou moins de marque (A1 à A4), options à la carte, la frise sur téléphone                    |
| `propositions-a3.html` | **A3 retenue**, cinq façons de montrer les prochains événements ; l'option 2 (bandeau) est choisie               |
| `pages-a3.html`        | A3 sur Événements, vue d'ensemble d'un événement, Commandes, Tarifs avec une fenêtre, Réglages, téléphone        |
| `pages-a3-suite.html`  | A3 sur Finances, Marketing (campagnes), Équipe (membres et rôles)                                                |
